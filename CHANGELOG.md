# Changelog

## 0.1.0-alpha.1 — 2026-09-06

First public alpha.

- Model-independent Economy, Balanced, Quality, and custom policy routing.
- Read-only Codex model discovery and account-mode diagnostics.
- Durable bounded workers with independent verification and resume.
- Isolated dependency-aware package coordination and deterministic integration.
- Attempt-local usage accounting and strict paired evaluation records.
- Guided project setup, versioned skill ownership, safe upgrade/removal, and schema 1 to 2 policy migration.
- Reproducible GitHub release archives with SHA-256 checksums and clean-install tests on Linux, macOS, and Windows.

Live availability still depends on the installed Codex version and account. This alpha has no published quality, token-savings, or cost-savings claim.
