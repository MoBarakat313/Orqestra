# Orqestra 0.1.0-alpha.1

This is the first public alpha of Orqestra, a configurable orchestration helper designed to work inside Codex.

The release includes model-independent routing, Codex model discovery, durable verified workers, isolated multi-package coordination, usage reporting, paired evaluation, and a project-local Codex skill. M7 adds one-command project setup, ownership-aware upgrades and removal, schema-backed configuration migration, cross-platform archive installation tests, and SHA-256 release checksums.

Start with the [installation guide](https://github.com/MoBarakat313/Orqestra/blob/v0.1.0-alpha.1/docs/INSTALLATION.md). Node.js 22 or newer is required. Live execution additionally requires a compatible Codex CLI and account; run `orqestra doctor` before relying on it.

This is alpha software. No model-quality, token-savings, or cost-savings claim is published with this release.
