# Orqestra 0.1.0-alpha.2

This release prepares Orqestra for easier public installation and evaluation inside Codex Desktop. It does not change orchestration runtime behavior from `0.1.0-alpha.1`.

The documentation now provides a one-prompt verified installation path, separate manual instructions for macOS, Linux, and Windows, a beginner command guide, model and worker-limit configuration examples, troubleshooting, and clearer upgrade and removal steps.

The README adds the Orqestra Safe Token strategy and an illustrative Astra routing comparison. The explanation describes how direct routing, focused worker context, configurable model assignments, bounded concurrency, bounded retries, and deterministic checks can reduce avoidable model work. It does not claim a fixed token or cost saving.

Public project material now includes a concise roadmap and a private vulnerability-reporting policy. Downloadable archives include the operational user guides while excluding historical planning, research notes, release-maintainer material, and contributor-only files.

Start with the [installation guide](https://github.com/MoBarakat313/Orqestra/blob/v0.1.0-alpha.2/docs/INSTALLATION.md). Node.js 22 or newer is required. Live execution additionally requires a compatible Codex CLI and account; run `orqestra doctor` before relying on it.

This is alpha software. No model-quality, token-savings, or cost-savings claim is published with this release.
