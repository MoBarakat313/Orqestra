# Security policy

## Supported version

Orqestra is currently a public alpha. Security fixes are made against the latest tagged alpha and the current `main` branch. Users should upgrade to the newest available release before reporting an issue that may already be resolved.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/MoBarakat313/Orqestra/security/advisories/new) for vulnerabilities involving command execution, path ownership, worktree isolation, credentials, authentication data, package integrity, or unintended disclosure.

Please include:

- The Orqestra version, operating system, Node.js version, and Codex version.
- A minimal reproduction using redacted or disposable data.
- The impact you observed and any relevant error output.
- Whether the issue requires a particular policy, task contract, or project layout.

Do not include credentials, account tokens, private repository contents, or personal data. Do not open a public issue for an unpatched vulnerability.

For ordinary defects and feature requests, use [GitHub Issues](https://github.com/MoBarakat313/Orqestra/issues).
